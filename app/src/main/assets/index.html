الإصدار 1.2 يضيف مساحة عمل بملفات قابلة للتبديل ومظهراً قابلاً للتخصيص مع حفظ تفضيلات المستخدم، مع الحفاظ على محرك اللغة وميزات الإصدار السابق. كما يتضمن فاحص المشروع وتصدير Web متعدد الملفات. لا يزال هذا الإصدار لا ينتج APK بذاته. الإصدار السابق يضيف فاحصاً للمشروع متعدد الملفات، إلى جانب تصدير مشروع لُغتي متعدد الملفات إلى صفحة HTML مستقلة تتضمن المفسّر ومدير الوحدات، ثم تشغّل ملف main.lughati والوحدات المستوردة داخل المتصفح. تبقى واجهات المستخدم محصورة بالعناصر والتفاعلات التي تدعمها مكتبة الواجهات الحالية. هذا ليس مترجماً إلى JavaScript ولا مولّداً لحزمة Android APK. التنفيذ عبر محلّل ومفسّر دون eval أو new Function.
