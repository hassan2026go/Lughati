# قاموس ومرجع لغة لُغتي — مسودة حيّة للإصدار 1.3

> هذا المرجع جزء من مشروع لُغتي، وسيُستكمل ويُراجع مع كل إصدار حتى يصبح الدليل التعليمي الشامل عند اكتمال اللغة. يصف فقط ما تنفذه النواة الحالية، ويميّز بوضوح بين المتاح وما لم يُنفّذ بعد.

## 1. لمحة عن اللغة

لُغتي لغة برمجة عربية تُكتب تعليماتها باستخدام كلمات عربية، وتُحلّل إلى بنية داخلية ثم ينفذها مفسّر اللغة. ليست مجرد قائمة أوامر نصية. يمكن إنشاء متغيرات ودوال وتراكيب تحكم وبيانات مركبة ووحدات وواجهات مستخدم محلية.

كل برنامج يبدأ عادة من الملف `main.lughati`. تُكتب الأوامر كسطور متتابعة، وتُحدّد الكتل بالأقواس `{` و`}`. لا يلزم وضع فاصلة منقوطة في نهاية التعليمة.

## 2. قواعد الكتابة الأساسية

- أسماء المتغيرات والدوال تقبل الحروف العربية واللاتينية والأرقام والشرطة السفلية، ولا يبدأ الاسم برقم.
- اللغة حساسة لاختلاف الحروف في النصوص والقيم، وأسماء المتغيرات يجب أن تطابق تعريفها.
- النصوص تقبل علامتي الاقتباس المفردة `'...'` أو المزدوجة `"..."`.
- التعليقات تبدأ بـ `#` أو `//` وتستمر حتى نهاية السطر.
- الأرقام تدعم الأعداد الصحيحة والعشرية.
- الفواصل `,` تفصل عناصر القوائم ووسائط الدوال ومداخل الكائنات.

مثال:

```lughati
# هذا تعليق
دع الاسم = "ياسر"
دع العدد = 12
اطبع "أهلاً " + الاسم
```

## 3. القيم وأنواع البيانات

| النوع | مثال | المعنى |
|---|---|---|
| رقم | `25` أو `3.14` | عدد صحيح أو عشري |
| نص | `"مرحبا"` | سلسلة نصية |
| منطقي | `صحيح` أو `خطأ` | قيمة منطقية |
| لا شيء | `لاشيء` | غياب القيمة |
| قائمة | `[10, 20, 30]` | مجموعة مرتبة قابلة للتعديل |
| كائن | `{اسم: "ليلى", عمر: 20}` | خصائص مرتبطة بمفاتيح |

| `حاول` | بدء كتلة معالجة أخطاء |
| `التقط` | التقاط الاستثناء وتسمية قيمته |
| `أخيراً` | كتلة تنفذ في نهاية المعالجة |

## 5. المتغيرات والإسناد

يُعرّف المتغير باستخدام `دع`:

```lughati
دع الاسم = "نور"
دع الرصيد = 100
الاسم = "سارة"
الرصيد = الرصيد + 50
اطبع الاسم
اطبع الرصيد
```

يجب تعريف المتغير قبل إسناد قيمة جديدة إليه. يمكن تعديل خاصية كائن أو عنصر قائمة بعد تعريفهما.

## 6. الإخراج والتعبيرات

```lughati
اطبع "مرحباً"
اطبع 5 + 3 * 2
اطبع "المجموع: " + نص(8)
```

ترتيب أولوية العمليات من الأعلى إلى الأدنى:
1. الأقواس واستدعاء الدوال والفهرسة وقراءة الخصائص.
2. النفي `ليس` والسالب الأحادي `-`.
3. الضرب `*` والقسمة `/` وباقي القسمة `%`.
4. الجمع `+` والطرح `-`.
5. المقارنات `<` و`>` و`<=` و`>=`.
6. المساواة `==` وعدم المساواة `!=`.
7. `و` ثم `أو`.

المساواة تقارن القيم وفق المساواة الصارمة في المحرك. القسمة وباقي القسمة على صفر ينتجان خطأ.

## 7. الشروط

```lughati
دع الدرجة = 87
إذا الدرجة >= 90 {
    اطبع "ممتاز"
} وإلا {
    اطبع "واصل التقدم"
}
```

يمكن تركيب الشروط باستخدام `و` و`أو` و`ليس`، ويمكن وضع شروط داخل كتل أخرى.

## 8. الحلقات

### طالما

```lughati
دع عداد = 1
طالما عداد <= 3 {
    اطبع عداد
    عداد = عداد + 1
}
```

### لكل

```lughati
دع أسماء = ["علي", "ليلى", "نور"]
لكل اسم في أسماء {
    اطبع اسم
}
```

تقبل `لكل` قائمة أو نصاً. تستخدم `كسر` للخروج و`تابع` لتجاوز الدورة الحالية.

## 9. الدوال

```lughati
دالة مربع(عدد) {
    ارجع عدد * عدد
}

اطبع مربع(6)
```

الدوال معرفة بالاسم، وتأخذ عدداً ثابتاً من المعاملات. استدعاءات الدوال العادية متزامنة في هذه النسخة؛ `انتظر` داخل جسم الدالة غير مدعوم بعد.

## 10. القوائم والكائنات

```lughati
دع أرقام = [10, 20, 30]
اطبع أرقام[0]
أضف(أرقام, 40)
احذف(أرقام, 1)
اطبع أرقام.طول

دع مستخدم = {اسم: "ياسر", نشط: صحيح}
اطبع مستخدم.اسم
مستخدم.نشط = خطأ
اطبع مستخدم["نشط"]
```

الفهرسة تبدأ من الصفر. خصائص الكائن يمكن قراءتها وتعديلها باستخدام النقطة أو الأقواس المربعة.

## 11. المكتبة الأساسية

| الدالة | الاستخدام | النتيجة |
|---|---|---|
| `طول(قيمة)` | نص أو قائمة أو كائن | طول النص/القائمة أو عدد مفاتيح الكائن |
| `أضف(قائمة, قيمة)` | إضافة عنصر إلى نهاية القائمة | طول القائمة بعد الإضافة |
| `احذف(قائمة, فهرس)` | حذف عنصر بحسب فهرسه | العنصر المحذوف أو `لاشيء` |
| `مفاتيح(كائن)` | استخراج مفاتيح الكائن | قائمة بالمفاتيح |
| `نوع(قيمة)` | معرفة نوع القيمة | نص يصف النوع |
| `نص(قيمة)` | تحويل القيمة إلى نص | نص |
| `رقم(قيمة)` | تحويل قيمة قابلة للتحويل إلى رقم | رقم أو خطأ |
| `مدى(نهاية)` | إنشاء أعداد من الصفر حتى ما قبل النهاية | قائمة أعداد |
| `مدى(بداية, نهاية)` | إنشاء مدى بين حدين | قائمة أعداد |
| `مدى(بداية, نهاية, خطوة)` | إنشاء مدى بخطوة مخصصة | قائمة أعداد |
| `يحتوي(مجموعة, قيمة)` | اختبار وجود قيمة في نص أو قائمة أو مفتاح في كائن | `صحيح` أو `خطأ` |

`مدى` لا يشمل حد النهاية، ويقبل خطوة موجبة أو سالبة غير صفرية.

## 12. معالجة الأخطاء والاستثناءات

```lughati
حاول {
    ارم "تعذر إكمال العملية"
} التقط المشكلة {
    اطبع "السبب: " + نص(المشكلة)
} أخيراً {
    اطبع "انتهت المحاولة"
}
```

يمكن أن يلتقط `التقط` الاستثناءات التي يطلقها `ارم` وأخطاء اللغة. كتلة `أخيراً` اختيارية لكنها تنفذ بعد المحاولة سواء نجحت أم فشلت.

## 13. المهام والانتظار

```lughati
دع المهمة = تأخير(500, "اكتمل الانتظار")
انتظر المهمة
اطبع "تابع البرنامج"
```

- `تأخير(مدة)` ينشئ مهمة مؤجلة، والمدة بالملي ثانية.
- `تأخير(مدة, قيمة)` يعيد القيمة بعد انتهاء المدة.
- `اجمع_المهام([مهمة1, مهمة2])` ينتظر اكتمال قائمة مهام ويعيد نتائجها.
- `انتظر` متاح في المستوى الأعلى من البرنامج، وليس داخل الدوال في 1.3.

## 14. الوحدات والملفات

ملف الوحدة ينتهي بالامتداد `.lughati`:

```lughati
# ملف: رياضيات.lughati
دالة مربع(عدد) {
    ارجع عدد * عدد
}
دع باي = 3.14159
صدّر مربع
صدّر باي
```

وفي `main.lughati`:

```lughati
استورد "رياضيات" كـ حساب
اطبع حساب.مربع(7)
اطبع حساب.باي
```

يجب أن يكون `استورد` و`صدّر` في المستوى الأعلى من الملف. يدعم مدير المشروع وحدات متعددة، ويمنع المسارات المطلقة ومسارات الرجوع للخلف والاستيراد الدائري.

## 15. واجهات المستخدم المحلية

تُنشأ الواجهة عبر `اعرض_واجهة`:

```lughati
دالة قل_مرحباً() {
    اطبع "تم الضغط على الزر"
}

دالة استقبل_النص(القيمة) {
    اطبع "كتبت: " + القيمة
}

اعرض_واجهة({
    عنوان: "تطبيقي",
    خلفية: "#edf4fb",
    لون_النص: "#183153",
    عناصر: [
        {نوع: "عنوان", نص: "أهلاً بك"},
        {نوع: "نص", نص: "واجهة محلية من لُغتي"},
        {نوع: "حقل", اسم: "الاسم", تلميح: "اكتب اسمك", قيمة: "زائر", عند_التغيير: استقبل_النص},
        {نوع: "زر", نص: "تنفيذ", عند_الضغط: قل_مرحباً},
        {نوع: "بطاقة", نص: "بطاقة معلومات"},
        {نوع: "فاصل"}
    ]
})
```

### خصائص الواجهة

- إعدادات عامة: `عنوان`، `خلفية`، `لون_النص`، `عناصر`.
- أنواع العناصر: `عنوان`، `نص`، `بطاقة`، `زر`، `حقل`، `فاصل`.
- خصائص شائعة: `نص`، `لون`، `خلفية`، `حجم`.
- الحقل: `اسم`، `تلميح`، `قيمة`، `عند_التغيير`.
- الزر: `نص`، `رسالة` أو `عند_الضغط`.
- `عند_الضغط` يشير إلى دالة معرّفة دون معاملات.
- `عند_التغيير` يشير إلى دالة معرّفة تستقبل قيمة النص الجديدة كمعامل واحد.
- يمكن للدالة تعديل متغيرات البرنامج ثم استدعاء `اعرض_واجهة` من جديد لإعادة بناء الواجهة بالقيم المحدثة.
- إذا لم يحدد الزر `عند_الضغط`، تبقى خاصية `رسالة` القديمة متاحة.

الواجهة محلية داخل المعاينة أو صفحة Web المصدّرة. هذه العناصر لا تنشئ وحدها اتصالاً شبكياً أو قاعدة بيانات أو خدمة مراسلة.

## 16. حدود الأمان والتنفيذ في 1.3

- حد التنفيذ العام: 50,000 خطوة.
- حد كل حلقة: 10,000 دورة.
- الحد الأقصى لعمق استدعاء الدوال: 100.
- `مدى` لا ينشئ أكثر من 10,000 عنصر.
- واجهة واحدة لا تقبل أكثر من 100 عنصر.
- حجم ملف اللغة في الاستيراد لا يتجاوز 500 كيلوبايت، وحد المشروع 100 ملف.
- ألوان الواجهة تمر بفحص CSS آمن، وحجم النص المدعوم من 8 إلى 64 بكسل.
- التنفيذ عبر محلل ومفسر؛ لا يستخدم `eval` أو `new Function`.

## 17. ما لم يصبح جزءاً من اللغة بعد

هذه أمور لا ينبغي تدريسها كميزات متاحة في 1.3: الفئات والوراثة، أنواع البيانات الثابتة، الواجهات العامة/المكتبات الخارجية، تعبيرات الدوال المجهولة، تنفيذ `انتظر` داخل الدوال، التخزين الدائم المنظم، قواعد البيانات، الشبكات، وتوليد APK مباشرة من اللغة. قد تصبح موضوعات لإصدارات مستقبلية بعد تصميمها وتنفيذها واختبارها.

## 18. الأخطاء الشائعة وكيفية إصلاحها

| رسالة الخطأ أو الحالة | السبب المعتاد | طريقة الإصلاح |
|---|---|---|
| المتغير غير معرّف | استخدام اسم قبل تعريفه أو اختلاف تهجئته | عرّفه أولاً باستخدام `دع` وراجع الاسم حرفاً بحرف |
| نص غير مغلق | نسيان علامة الاقتباس الأخيرة | أغلق النص بنفس نوع علامة الاقتباس التي بدأ بها |
| متوقع `}` | كتلة شرط أو حلقة أو دالة لم تُغلق | أضف القوس الناقص ووازن الأقواس المفتوحة والمغلقة |
| تعبير غير صالح | كتابة تركيب لا تقبله القواعد | راجع ترتيب الكلمات والأقواس والفواصل |
| عدد المعاملات غير صحيح | استدعاء دالة بعدد وسائط مختلف عن تعريفها | طابق عدد القيم مع عدد معاملات الدالة |
| العملية تتطلب قيمة رقمية | تمرير نص أو قيمة غير رقمية لعملية حسابية | تحقق من القيمة أو حوّلها باستخدام `رقم` عند ملاءمة ذلك |
| القسمة على صفر | المقسوم عليه يساوي صفراً | افحص المقسوم عليه قبل تنفيذ العملية |
| معالج الحدث يجب أن يشير إلى دالة | وضع نص أو قيمة عادية في `عند_الضغط` أو `عند_التغيير` | عرّف دالة باسم ثم استخدم اسمها كقيمة الخاصية |
| الملف المطلوب غير موجود | اسم الوحدة أو مسارها لا يطابق الملف | تحقق من وجود الملف وامتداد `.lughati` وصحة الاسم |
| استيراد دائري | وحدتان تستورد كل منهما الأخرى عبر سلسلة من الاستيرادات | أعد تنظيم الوحدات لإزالة الحلقة |
| تجاوز حد التنفيذ | حلقة لا تنتهي أو برنامج ينفذ تعليمات كثيرة | راجع شرط الحلقة وقلل العمل داخل التكرار |

### طريقة منظمة لتشخيص المشكلة

1. اقرأ رقم السطر في رسالة الخطأ.
2. افحص السطر نفسه والسطر السابق؛ فقد يكون القوس أو الاقتباس الناقص قبله.
3. تأكد من تعريف المتغيرات والدوال قبل استعمالها.
4. اختبر جزءاً صغيراً من البرنامج باستخدام `اطبع`.
5. شغّل «فحص المشروع» عند العمل على عدة ملفات؛ فهو يفحص الصياغة ووجود الوحدات ودورات الاستيراد والملفات غير المستخدمة.
6. لا تعتبر نجاح فحص الصياغة دليلاً على أن منطق البرنامج صحيح؛ شغّله واختبر النتائج أيضاً.

## 19. مسار تعلّم مقترح

1. ابدأ بالتعليقات والمتغيرات والنصوص والأرقام و`اطبع`.
2. تعلم العمليات الحسابية والمقارنات والقيم المنطقية.
3. اكتب شروطاً باستخدام `إذا` و`وإلا`.
4. أنشئ حلقات باستخدام `طالما` و`لكل`، وجرّب `كسر` و`تابع`.
5. قسّم البرامج إلى دوال مع معاملات و`ارجع`.
6. تدرب على القوائم والكائنات وتعديلها.
7. أضف معالجة أخطاء باستخدام `حاول` و`التقط` و`أخيراً`.
8. أنشئ ملفات وحدات واستوردها وصدّر عناصرها.
9. جرب المهام المؤجلة باستخدام `تأخير` و`انتظر`.
10. أنشئ واجهة محلية واربط الحقول والأزرار بدوال اللغة.

### تمارين قصيرة

- أنشئ متغيرين رقميين واطبع مجموعهما ومتوسطهما.
- اكتب دالة تعيد الأكبر بين رقمين باستخدام شرط.
- أنشئ قائمة أسماء واطبع كل اسم باستخدام `لكل`.
- أنشئ كائناً يمثل مستخدماً وعدّل خاصية `نشط`.
- اكتب برنامجاً يلتقط محاولة قسمة غير صالحة برسالة واضحة.
- أنشئ وحدة للعمليات الحسابية واستورد دالة منها.
- أنشئ عداداً تفاعلياً وزراً يزيد قيمته وحقل اسم يحدّث عنوان الواجهة.

## 20. سياسة تحديث القاموس

هذا المرجع ليس قائمة وعود مستقبلية. عند إضافة كلمة أو قاعدة أو دالة إلى المحرك:

- تُوثق الكلمة ومعناها وصيغتها وموقعها في القواعد.
- يضاف مثال بسيط ومثال عملي قابل للتشغيل.
- توضح أنواع الوسائط والقيم المعادة وحدود الاستخدام والأخطاء المحتملة.
- يضاف اختبار آلي أو مثال تحقق للميزة.
- تذكر الميزات غير المنفذة في قسم مستقل ولا تدرّس على أنها مدعومة.

**الحالة الحالية:** مسودة حيّة للإصدار 1.3، وليست القاموس النهائي بعد. سيُستكمل الشرح التفصيلي والفهرس والأمثلة والتمارين مع استقرار بقية مكونات اللغة.
